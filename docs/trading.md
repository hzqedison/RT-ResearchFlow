# 交易流程与使用范围

交易开通、连接检测、本人确认的真实委托与去敏诊断集成在同一款产品中，不是另一款独立“交易版”。

## 当前能力

- 核实券商服务、客户端及本机权限的开通引导。
- 检查同花顺 A 股模式、中信标记和适配表单；无法可靠识别则停止。
- 代码、限价、数量的填写与回读；表单预览不提交订单。
- 本人核对并经过主进程系统确认后，尝试处理单笔主板限价买卖。
- 按精确委托编号选择单行并处理本人确认的单笔撤单，不使用全撤。
- 在同花顺本机查看委托和成交页面，不采集或导出账户表格。
- 导出去敏运行结果，帮助定位权限、页面布局和连接状态。

执行桥接目前适用于 **Mac 同花顺**。Windows 可用投研、AI、数据源与开通引导，但不能执行同花顺实盘。不是中信证券或同花顺官方下单 API，不使用 Windows 后台执行替代 Mac 本机。

真实交易代码路径已提供，但尚未在测试者当前客户端与中信账户上验证受理、成交及撤单成功；开源参考代码、编译与隔离测试均不提供这个保证。

## 本人使用顺序

1. 通过券商及软件官方渠道核实接入要求，手动登录正确的同花顺中信账户，不发送账户资料。
2. 进入“量化开通 > 真实交易”，申请必要的辅助功能和自动化权限，然后“检查同花顺连接”。
3. 先使用“填写表单并回读（不提交）”核对代码、价格与数量。
4. 如本人决定使用实盘，再核实风险与委托上限并明确启用本次会话；重启后授权关闭。
5. 每筆操作核对应用与系统确认框。系统默认取消；同花顺原生弹窗仍由本人核对、确认或取消，不由本工具自动点击。
6. 等待确认、超时或回报不明时，先在同花顺核对委托与成交，再显式解除重复请求保护，不能自动重发。
7. 反馈问题只使用“导出去敏运行结果”；不要发送账号、密码、Key、资金、持仓、订单编号或原始日志。

## 必须区分

委托受理不等于成交。单笔撤单不能撤销已成交部分。开通引导登记不等于交易授权，交易连接也不能代替完整投研数据源。

当前不支持科创板、创业板、ETF、转债、自动登录、资金转账、自动调仓、策略自动触发或无人值守。不得通过修改宣传文案把尚未支持的能力描述为已可用。
