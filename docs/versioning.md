# 版本与发布约定

## 产品版本

用户可见版本从 **1.0** 开始，后续新的对外迭代使用 **1.1、1.2、1.3** 依次递进。

构建与更新工具使用标准三段版本：

| 产品展示 | package.json / 应用内部 | 发布标签 |
| --- | --- | --- |
| 1.0 | 1.0.0 | v1.0.0 |
| 1.1 | 1.1.0 | v1.1.0 |
| 1.2 | 1.2.0 | v1.2.0 |

同一轮发布前的修复沿用该轮编号。发布后再迭代必须升级版本，不能覆盖已公开附件、只改文件名冒充新构建或重用旧安装包。1.9 后按整数递进为 1.10。

## 同一产品，同一编号

投研、AI、策略、数据源与交易流程属于同一款产品。Windows、Mac Apple 芯片和 Intel 仅按系统及架构选择安装文件，不单独定义功能版本。

各平台构建必须使用同一源码、应用版本与发布编号；真实能力仍须按模块公开限制，不能为了统一介绍而把 Mac 专用交易桥接说成 Windows 可执行。

package.json 版本变化只修改必要元数据，不能顺带改动依赖、锁文件、appId、包名或数据路径。版本、标签、安装文件名、首页与发布说明保持对应关系。

## 升级与数据

固定沿用原安装目录，更新程序文件而不是每次新增一个运行目录。保留本地数据库、配置与加密凭据，更新前备份，不删除数据以绕过安装错误。

发布源使用本仓库 GitHub Releases。当前仍为完整安装包升级；差分清单、分块文件、下载校验及失败回退尚未集成，不将覆盖安装称为真正增量更新。未来更新先提示、由本人确认安装，不强制关闭正在使用的应用。

## 历史版本

0.1.0-beta.N 作为既有测试历史保留。本轮从 beta.9 进入产品版本 1.0，后续不继续使用 beta.10 作为正式产品递进编号。

版本号表示本轮产品交付编号，不表示真实券商账户已验证、商业签名或 Apple 公证已经完成。
