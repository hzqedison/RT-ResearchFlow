## 结果记录原则

- 每项测试分别记录版本、系统与 Mac 架构（如适用）、操作、可见结果和时间。
- CI 与测试者设备是不同验证范围；一方通过不自动代表另一方通过。
- 只有完成对应场景并留有可复核结果后，才能标为“已通过”；没有运行或结果不完整时保持“待验证”。
- 1.1 已接入错误编号、脱敏预览和手动本地反馈导出；本地运行时关联检查的通过范围见历史证据。反馈只包含对应场景所需的脱敏信息，不附真实密钥或账户资料。
- 同版本重装、跨版升级、mock 密钥与真实 OS 存储分别登记；CONDITIONAL 不改写为全面放行。下一步原生升级与 Keychain 待办见架构任务记录，原有未完成任务保持未完成。
