# 测试反馈

请按下面几项描述遇到的情况。能填多少填多少；不需要提供账号或密钥。

| 项目 | 请填写 |
| --- | --- |
| 版本 / 系统 | 例如：1.0 / Windows，或 1.0 / Mac（arm64 或 x64） |
| 想做什么 | 例如：配置模型、查看行情、保存设置或退出应用 |
| 实际结果 / 时间 | 实际看到或发生了什么，以及大致发生时间；请抄录屏幕上可见的提示文字 |
| 可选：错误编号或去敏诊断附件 | 如果界面显示错误编号，可填写；也可附去敏后的诊断信息。请先遮挡个人信息 |

**请勿发送**完整 API Key、密码、账户资金、持仓明细或其他可识别个人账户的信息。需要反馈交易相关问题时，请由账户本人先去敏，只描述操作步骤、可见结果和时间。

本模板仅依赖当前可见提示。统一错误编号与标准脱敏反馈包是本轮架构目标，入口是否已有由源码盘点确认。
