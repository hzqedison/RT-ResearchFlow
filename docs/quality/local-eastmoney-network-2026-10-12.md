# 本机东方财富日线连接诊断

日期：2026-10-12。适用范围为本机只读请求，不代表所有网络环境。

## 实测结果

- 东财官网：DNS、TCP、TLS 与 HTTP 均正常，HTTP 200。
- 日线接口所在域名根路径：DNS、TCP、TLS 正常，HTTP 404；这说明根路径不存在，不是整个域名无法连接。
- 公开日线查询：DNS、TCP、TLS 正常，但未收到 HTTP 响应，连接错误为 ECONNRESET。
- 使用相同参数比较 .NET 直连与系统代理路径，两者均未取得完整结果。仅使用已有代理配置，没有修改代理、DNS 或系统设置。
- 未读取或传输用户 API Key、Cookie、券商账户或持仓数据。只查询公开股票样本。

## 与正式包隔离测试的对照

正式 1.21 的 Windows、Apple Silicon Mac、Intel Mac 安装包，在隔离环境均通过真实公开数据测试。腾讯、新浪、东方财富抽样日线全部可用，免费涨停规则也完成了扫描与证据落库。

[三端实测记录](https://github.com/hzqedison/RT-ResearchFlow/actions/runs/38253847793)

这表明不能将本机观察泛化为所有 Windows 的程序故障。网络出口、源站策略或临时限制是待排查因素，不是已经证实的根因；更换代理路径也没有直接解决此次问题。

## 配置边界

代码中的全新配置、且未启用 Tushare 时，默认日线来源为腾讯、东方财富、新浪。已有用户保存的来源选择被保留，不因本轮诊断强行改写。

本轮只核查了默认配置定义，未宣称已单独验收图表、初始化等每个业务消费者的故障转移。专业竞价、筹码等数据与基础日线仍是不同能力；公开日线连接错误不是 Tushare Token 验证结果。

没有证据支持以购买 Tushare Key、修改系统代理或发布新版本作为此次连接重置的修复。本轮不改变程序、安装包或个人配置。
