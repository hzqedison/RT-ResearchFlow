# 1.17 组合资金回测候选

状态：本地隔离验收、三端原生安装包及 Windows 安装生命周期通过，1.17 已正式发布。证据见 `release-1.17-acceptance.md`。1.16 历史包不改变。

路径：策略评估 → 组合资金回测 → 已保存短线或实验室信号 → 交易日推进 → 本地报告及重启读取。明确资金、现金预留、最多持仓、单股预算、买入单位、费用和滑点；金额为整数分。观察到持仓复权变化时不按因子比例猜测股数或分红，缺少事实就停止；行情缺口不以前值冒充当前市值。

资金输入可使用手动情景或相同起始日的已核对账户期初。后续实际成交、当前余额和未知委托不倒灌历史。仅长期做多研究，日线撮合、买入单位、费用、信号时点及缓存价格口径未完整核验，报告保持研究限制；没有真实券商连接或订单提交。不支持自动公司行动、真实逐笔容量或实盘可卖数量。完整 5.3 仍待更广验收。

验收待办：整数分预算与最低费用、同时信号与稳定排序、T+1、同日退出资金不可复用、止盈止损与跳空、缺失行情/因子变化、期末持仓、无样本、日期和账户版本校验、不可变报告及事务失败、可信 IPC、实际打包程序运行报告和退出重启、三平台原生安装以及 Windows 数据保留。
