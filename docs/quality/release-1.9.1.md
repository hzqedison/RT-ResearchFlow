# RT-ResearchFlow 1.9 修订版（1.9.1）

此版本延续 1.9 的 PDF 启动、选股字段质量及回测执行修复，仅调整数据扩展的交付方式，不包含开发中的 1.10 看板布局。

## 首次使用

- 腾讯、东方财富、新浪等基础日线及东财研报索引不依赖 Python 扩展。
- AKShare、通达信/mootdx、i问财/pywencai 按需安装。先从 Python 官网取得 Python 3.11 或以上（建议 3.12），在配置中心选择解释器，再安装所选扩展。
- 点击安装才从 PyPI 下载 wheel；不默默安装，不修改系统 Python，也不改动已有研究数据。
- 创建环境、下载依赖与导入验证均有阶段提示；安装失败保留原配置并清理本次新建的环境。
- i问财仍可能需要本机 Node.js 及本人 Cookie；不绕过验证码、登录或收费权限。

## 交付差异

Windows 与 Mac 是同一个产品。公开包不携带此前个人测试包的 Python 运行库，避免把尚未完成分发检查的运行库一起公开。

1.9.0 已公开的源码标签不移动；新的交付源码与安装包统一使用 1.9.1，清楚区分修订包。不是把旧 1.9.0 安装包改名。

## 验收状态

候选包必须通过类型检查、按需安装契约、实际包启动/设置/退出、PDF/canvas/SQLite，以及实际 AKShare 首次安装。Windows 与两种 Mac 架构分别留证；任一平台未通过则不宣称三平台交付完成。

本文是候选版本说明，不是测试通过记录。通达信及 i问财的所有上游连接、所有机器首次 Python 安装、Apple 公证和真实账户交易不在已有证据范围内。
