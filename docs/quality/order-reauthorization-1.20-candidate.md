# 1.20 恢复后会话授权候选证据

## 实际问题与修正

现有服务恢复后要求新的账户会话授权，因而将 canPrepare 保持 false；界面却把 canPrepare 当作启用授权按钮的前提。全部意图核对完仍不能重新授权，形成产品死锁。新增主进程 canAuthorizeLive 投影和对应页面门禁，保留原订单准备、逐笔确认和禁止重放规则。

缺少新字段的旧投影保留原门禁；明确 false 不被 fallback 覆盖，非布尔值拒绝投影。状态未同步、本操作回报未知、仍有未决意图、存储/恢复阻断及执行未证明退出时不开放授权。
