# RT-ResearchFlow 1.13 candidate

Not published. The stable release remains 1.12.

- Save one AI provider without discarding unsaved keys or settings in other rows.
- Preserve existing credentials when a key field is omitted or blank.
- Explicitly remove a locally stored provider key through that row's checkbox and Save button, including its legacy selected-provider copy and provider-selection lists.
- Distinguish locally readable credentials, unavailable OS secure storage, unreadable encrypted data, and unconfigured providers. Local readability is not proof of remote authorization or model support.
- Validate partial updates and save them transactionally. Invalid input or failed encryption preserves the previous configuration; raw database/platform errors must not reach the UI.

The candidate requires regression, real packaged application restart checks, and three-platform native acceptance before release. No live Tushare key or brokerage order is used by these checks.
