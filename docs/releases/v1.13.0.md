# RT-ResearchFlow 1.13.0

同一个投研工作台，提供 Windows 和 Mac 安装包。本次重点修复 AI 配置保存与系统密钥存储的可靠性。

## 本次更新

- 保存某个模型厂商配置时，不再覆盖其他厂商尚未保存的输入和全局设置草稿。
- 保存全局设置时，保留其他厂商未提交的密钥输入；空白密钥输入不会误清除已绑定密钥。
- 增加明确的密钥移除操作。保存移除后，再次启动仍保持未配置状态，并同步移除相关分析优先级选择。
- 区分未配置、本地可读取、系统密钥存储不可用和密钥不可读取，避免把存在加密字段误认为可使用。
- 配置写入使用事务，失败时不部分保存；不会退回明文保存密钥。
- 保留清晰的 Tushare Key 绑定入口：配置中心 → 数据源 → Tushare。填写自己的 Key 后执行保存及只读验证；Key 验证和各数据接口权限不是同一件事。

## 已完成的验收

- Windows、Apple 芯片 Mac、Intel Mac 均通过实际安装包启动、设置和退出检查，以及首次使用扩展安装检查。
- 三端使用随机无效测试密钥和本机回环地址，验证系统加密存储、保存后重启读取，以及移除后再次重启保持未配置；没有调用真实模型服务。
- Windows 覆盖安装、卸载后的用户数据保留及共享 Python 不受影响检查通过。
- 本机原目录覆盖升级成功，安装前后六个数据库及配置文件的校验值保持一致；升级后启动、打开设置和退出测试通过。

## 使用边界

本轮没有用户可用的 Tushare Key，因此不宣称已通过真实 Key、套餐权限或所有行情数据接口的在线验收。未绑定 Tushare 不影响应用安装，但需要该源的功能仍取决于 Key、接口权限和本地数据完整性。公开来源不能被当作集合竞价、筹码或历史回测数据的等价替代。

本轮未连接券商、未提交任何订单；密钥保存验收不代表实盘交易链路已可用。Mac 安装包不宣称经过 Apple 公证。
