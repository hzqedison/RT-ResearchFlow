# RT-ResearchFlow 1.6

## 免费短线观察的可用性与来源质量

- 默认展示公共缓存中的全部股票，缺少连板或炸板字段不会被悄悄隐藏；具体筛选会排除未知字段并说明数量。
- 读取失败时明确显示提示，同时保留此前资料，不把旧日期或旧缓存当作当前来源正常。
- 公共观察使用与主工作台一致的可访问筛选控件；点击股票即可查看日K。已有主工作台资料时，公共列表默认收起。
- 逐行判断返回字段是否齐备，不再用整个批次的标记代替单只股票的数据状态；合法的0元与未知金额分别显示。
- 强化公共来源数值、计数、日期与行情一致性校验，仅将通过核对的记录写入独立缓存。
- 来源日期、行情核对时间和数据新鲜度分别说明。行情价格吻合不证明上游返回的日期正确，也不证明完整市场覆盖。

## 范围说明

公共涨停观察用于只读研究，不混入原有策略评分或交易订单；它不等于竞价、筹码、分钟线和专业权限的完整替代。真实交易仍由本人逐笔确认。

内部版本为 `1.6.0`，源码功能对 Windows 与 Mac 共用。平台安装、升级和发布证据应以本版本验收记录为准，不能用源码检查冒充跨平台安装测试。
