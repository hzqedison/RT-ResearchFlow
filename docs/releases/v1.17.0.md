可使用手动资金情景或同日起始的本地账户期初声明；报告固定参数和事实摘要，本机保存并可重启读取，旧报告原口径保持不变。Windows 与 Mac 属于同一产品。

日线撮合、价格口径、历史信号当时可得性和费用属于明确的研究限制，不证明实盘成交或策略盈利。不操作券商、不下单；没有有效 Tushare Key，不声称线上认证。只有三端原生安装、持久化和 Windows 安装生命周期通过后正式发布；不覆盖历史安装包。
