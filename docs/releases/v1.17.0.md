# RT-ResearchFlow 1.17

在现有策略评估页新增“组合资金回测”：所选短线或实验室信号共用现金和仓位预算，明示现金预留、买入单位、费用、滑点和持有期。开盘入场不使用当日稍后卖出释放的资金；缺少持仓价格不伪造市值，观察到未支持的公司行动即停止推进。

可使用手动资金情景或同日起始的本地账户期初声明；报告固定参数和事实摘要，本机保存并可重启读取，旧报告原口径保持不变。Windows 与 Mac 属于同一产品。

日线撮合、价格口径、历史信号当时可得性和费用属于明确的研究限制，不证明实盘成交或策略盈利。不操作券商、不下单；没有有效 Tushare Key，不声称线上认证。只有三端原生安装、持久化和 Windows 安装生命周期通过后正式发布；不覆盖历史安装包。

三端及生命周期验收已通过，正式版本为 1.17（内部版本 1.17.0）。Tushare 绑定入口仍位于“配置中心 → 数据源 → Tushare Key 绑定与验证”，无需先提供 Key 才能安装产品。
