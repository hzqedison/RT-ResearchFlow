# RT-ResearchFlow 1.15

本轮改善数据范围诊断与初始化判断；Windows 与 Mac 属于同一产品。

## 改进

- 股票、日线缓存诊断复用关键数据质量结果，字段、复权或覆盖缺口不再仅凭有记录显示正常。
- 初始化只有在目标范围得到核验后才跳过同步；少量个股历史不会被当作全市场历史底座。
- 按真实交易日区分长假、开盘前和结算后的截止日；日历未知时优先给出补齐日历入口，已有数据保留。
- Tushare 绑定和只读验证入口继续位于配置中心的数据源页；免费基础功能不强制要求 Key。
