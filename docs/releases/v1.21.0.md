# RT-ResearchFlow 1.21

本轮补强滚动研究的数据可复现性。三端原生验收、Windows 安装生命周期及原字节发布检查通过后才提供正式安装包，公开状态以 GitHub Releases 为准。

## 变化

- 保存新协议时一次性冻结所选信号、整段日线、复权因子、数据来源和日历。训练候选及样本外窗口使用同一数据底座，缓存刷新或删除不会偷偷改变后续结果。
- 页面显示共同数据的日期、信号数、日线数、冻结时间与摘要，各报告保留自己的窗口输入摘要。
- 冻结数据丢失、校验失败或报告不属于该快照时停止推进，已完成结果保留，不自动改用当前数据。
- 旧协议和报告保持可读。没有共同快照的旧研究不追加新结果，也不在当前时点悄悄补成历史快照；需核对参数后新建协议。
- 研究与快照同事务保存，并限制本地容量；存储失败不会留下半份协议。

## 限制

冻结的是创建协议时已有的本地数据，不证明历史时点信号已经可得，不能消除当前股票池偏差、价格口径或日线撮合限制。各窗口仍独立重置预算，不能拼接为连续实盘净值；不提交真实订单，也不替代券商兼容或 Tushare 权限验证。

三端发布须通过新增的实际应用保存/运行界面、共同快照、删除缓存、快照缺失及重启检查。通过证据在发布附件单独记录，不因代码存在而声称已验收。
