# RT-ResearchFlow 1.16

新增统一产品内的本地账户账本，入口：长线趋势 → 持仓总览 → 账户账本。Windows 与 Mac 使用同一功能和数据契约。

- 明确核对期初现金及持仓，逐笔记录已成交明细、佣金、印花税、过户费及资金流水。
- 整数分核算现金、移动平均成本和已实现盈亏；未知费用保留未知，不自动填零。
- 成交编号去重、并发修订检查和显式冲销更正；原始事实不删除，退出后本机持久化。
- Tushare Key 绑定与只读验证入口始终保留在“配置中心 → 数据源”。没有 Key 仍可使用免费基础功能。

本地账本不是券商实时账户，录入明细不触发下单；可用资金、可卖数量、公司行动、融资融券及资金约束组合回测未在本轮接入。没有有效 Tushare Key，不声称通过真实线上认证。隔离测试不代表实盘兼容或零缺陷。仅在三端原生安装检查及 Windows 安装生命周期通过后公开发布，附件提供验收记录与 SHA256。
