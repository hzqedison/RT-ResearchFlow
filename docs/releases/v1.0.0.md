# RT-ResearchFlow 1.0

产品展示编号 1.0，内部应用版本 1.0.0，对应发布标签 v1.0.0。后续迭代按 1.1、1.2 递进，不继续按 beta.N 编号。

## 本轮变化

- 首页按用户任务与特色彻底重写，不再以 Mac 适配或来源仓库作为主要产品定位。
- 突出多数据源、研报索引、i问财条件查询、AI 配置与研究、策略验证、本人确认交易及本地复盘。
- 强调一个产品、一条工作流，安装平台与架构信息只在下载及必要兼容说明中展示。
- 维护身份统一为 hzqedison，来源和必要署名集中至底部致谢与 NOTICE，许可证及原有版权不变。
- 同步产品描述、版本规则和技术文档，不改依赖、应用身份、数据路径或交易安全边界。

## 发布状态

本说明对应当前源码迭代，不表示新安装包已经发布。实际可下载文件及构建记录以 GitHub Releases 为准；不能只重命名 beta.9 安装包冒充 1.0。

当前不新增无人值守交易、Windows 同花顺执行、全部专业接口免费替代或 GitHub 增量更新能力。真实客户端兼容仍需本人去敏测试。

## 同轮新增：应用更新入口

配置中心可检查 GitHub 正式/测试发布，按系统与芯片选择直接安装包，选择下载盘符、取消下载，并核对文件大小与 SHA-256 后打开文件位置。Windows 默认下载位置跟随安装盘，模块不自动退出、覆盖安装或改动用户数据库。本轮仍为完整安装包下载；增量下载、自动安装和失败回滚尚未完成。

本模块已写入源码，尚未运行隔离检查或重新打包，不能把代码变更当作已验证安装包。

## 同轮新增：免 Key 交易日历

- 启动时补齐已公布范围的上交所日历；“补齐交易日历”和月度调度不再强制要求 Tushare Token。
- 使用 2024 至 2026 年官方年度休市安排识别节假日与周末补班；范围外保持未知，不推测未来日期。
- 免费兜底只插入缺失日期，保留已有记录，对来源差异和覆盖不足给出提示。
- 日线与核心基准按应用现有盘后截止和最近完成交易日判断，避免长假造成自然日误报。
- 竞价行情没有被日历代替：没有竞价事实时仍提示相关功能缺数据。

本轮是尚未发布的 1.0 源码接入，未运行检查、交易客户端或安装包构建，当前本机安装版尚未替换。
