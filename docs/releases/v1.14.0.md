# RT-ResearchFlow 1.14.0

同一个投研工作台，本次改进免费初始化路径、数据状态解释和后台任务提示。

## 更新内容

- 未绑定 Tushare 时，优先提供免费股票资料同步，不再把绑定 Key 当作基础功能的前置门槛。
- Tushare、AI、历史日线和题材入口仍明确可见，并标记可选增强；Key 入口没有隐藏。
- 同步任务可启动不代表本地数据已补齐；缺失、未知或未核验的事实不会被当作已具备数据。
- 模块或提供方错误保留原严重度，仅限制对应能力；本地数据库错误仍阻断基础使用。
- 一键初始化期间显示执行中状态。没有信号不再被解释为市场没有机会。
- 保留 1.13 的局部配置保存、草稿保留、系统加密存储和显式移除密钥保护。
- Windows 构建检查在任一命令失败时立即停止，避免后续成功掩盖前面的失败。

## 使用边界

Tushare Key 入口：配置中心 → 数据源 → Tushare。绑定、只读认证、接口权限和本地事实完整性是不同检查；本轮没有可用用户 Key，不宣称线上认证或付费接口权限已验收。

本轮没有连接券商或提交订单，不宣称实盘链路已验收。竞价、筹码和完整历史策略仍需要对应事实，不能用普通报价或当前题材伪装。所有短线依赖、历史跨版升级及 Mac 用户环境升级并非已全面验证。Mac 安装包不宣称经过 Apple 公证。
