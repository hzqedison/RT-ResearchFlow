# RT-ResearchFlow 1.7

资讯、AI 研究、行情与策略验证、本人确认交易，继续在同一个工作台中使用。Windows 与 macOS 为同一版本，不拆分产品功能。

## 本轮更新

- 将免费的数据扩展依赖与私有 Python、Node 运行环境随安装包提供，减少首次使用时手动安装系统环境的步骤。
- AKShare、通达信扩展与 i问财扩展使用独立的依赖目录，避免不同数据源相互污染。扩展就绪不代表上游数据服务始终可用，也不替代需要开通的接口权限。
- 加强 Windows 安装路径与升级保护，针对旧路径记录、空格和中文目录进行隔离验收；保留本地数据，不将异常旧路径作为可删除目录。
- 对 Windows x64、Apple 芯片 Mac 与 Intel Mac 分别进行原生构建和安装检查。版本、源码、安装包及校验和对应同一轮发布。

## 使用说明

- 使用免费的数据源仍需要网络。历史行情、题材、竞价和策略信号分别有自己的数据准备过程；某一项可用不表示所有模块已准备完毕。
- Tushare 的受限接口仍需要有效权限；免费的替代源不保证能提供完全相同的字段、历史覆盖或竞价数据。
- 真实交易必须由账户本人逐笔确认。交易模块的代码与隔离检查不代表已在你的券商账户上完成真实委托验证。
- 请下载与本机芯片对应的安装包。Mac 的最低系统要求维持 macOS 12，但没有 macOS 12 实机验收；未承诺 Apple 公证或 Windows 签名信誉。

## 更新与数据

这是统一产品的 1.7 版本。正常升级沿用应用身份和已有数据，不以新建一套安装目录作为默认升级方式。异常旧安装记录必须经过安全检查，不能通过删除未知文件或清空业务数据库解决。

本发布保留原有开源许可、版权声明和随包第三方说明。安装包的实际验收范围与 SHA-256 以随发布附带的证明文件为准。
