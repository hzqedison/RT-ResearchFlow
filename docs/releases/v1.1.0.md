# RT-ResearchFlow 1.1

产品展示编号 1.1，内部版本 1.1.0，目标发布标签 v1.1.0。

## 本轮改进

### 交易日历与数据质量

- 无需 Key 或 Tushare Token，即可在已支持的官方年度公告范围内使用交易日历；公告范围外保持未知。年度计划不覆盖临时休市、个股停牌及所有证券的实际交易状态。
- 日历覆盖按区间逐日检查，避免远期孤立记录掩盖中间缺口。新补日期遵从已有闭市数据，显式 `null` 前驱保留为未知，不跨越缺口推断上一交易日。
- 核心基准先按 `asOf` 截止日排除未来数据，再计算覆盖和新鲜度；仅有未来数据时不再错误判定可用或误报覆盖/新鲜度问题。
- 日线质量采用交易日与盘后截止口径；盘后补漏不因缺少 Tushare Token 被整体跳过，实际行情仍按所选来源能力和权限获取。免 Key 日历不意味着免费实时竞价或所有专业数据均可用。
- 诊断同步在成功、空结果或失败时，均先持久化刷新质量快照，再返回结果或报错，使诊断状态反映本次同步事实。

### 配置、数据与退出

- 支持按 AI 厂商保存设置，未填写其他厂商密钥不阻塞保存，空白输入不随意清除已有加密密钥。保存配置不等于模型连接或调用已成功。
- 数据库迁移前生成并验证 SQLite 一致性快照；已有近期旧式原文件备份也会重新生成可信快照。
- 后台调度增加运行代次保护，防止停止或重排后旧任务完成时重新登记、影响新一代任务。
- 启动初始化等待数据库准备完成；退出和重启停止后台入口，并有界等待已登记任务和本地研究连接。部分旧后台业务尚未纳入统一任务登记；退出阶段保留数据库连接至进程回收，完整任务生命周期迁移仍待完成。

### 受信调用与错误反馈

- 配置、AI、诊断、数据导出及多数据源相关入口使用受信主窗口 IPC 调用检查。
- 失败提示提供问题编号，可在诊断页查看对应的白名单技术信息、预览脱敏反馈，并手动保存到本人选择的本地文件；不自动上传。
- 本轮运行时测试验证了错误编号关联、预览与导出一致，以及配置重启保留。反馈事件仅保存在当前进程内，旧事件不会跨重启保留。

### GitHub 更新下载

- 改善完整安装包下载的取消、失败残留处理和中文操作提示；采用原子保存，保留未知同名文件，不把未完成下载作为安装包交付。
- 不支持硬链接的下载目录会提示更换目录。更新仍使用完整安装包，由本人执行安装；尚不提供真正差分增量或自动覆盖升级。
