# RT-ResearchFlow 1.5

## 免费历史日线进度可见

- 数据源和诊断页面新增自动更新的日线任务进度卡，不再需要反复手动检查。
- 展示股票处理进度、本轮写入行数、最近记录股票、任务开始时间和最近进度时间。
- 区分准备股票列表、正在拉取、批次等待、来源冷却、已中断、本轮完成、部分失败和失败。
- 进度读取失败时保留上次记录并标明尚未更新，不因此停止、重启或重复拉取后台任务。
- 任务处理进度包含已尝试但失败的股票；100% 不代表字段齐备、行情覆盖或复权质量已经合格，仍以数据质量检查为准。

## 免费短线数据研究入口

- 支持通过已配置的本地 AKShare 扩展检测东方财富涨停池，并与同日行情核对后存入独立研究缓存。
- 涨停监控可展示独立公共来源记录；这不等于完整替代竞价、筹码和其他专业接口，也不等于自动启用实盘交易。

## 更新与验收边界

- 内部版本为 `1.5.0`，Windows 和 Mac 属于同一产品迭代。
- 更新保留已有数据；正在同步时不要为了查看新界面而强行退出旧程序。
- 本说明描述源码实现。跨平台安装包、安装升级路径和真实外部数据源的验证，以对应发布的验收记录为准；没有安装包证据时不得据此声称已经完成发布。
