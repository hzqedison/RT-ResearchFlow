# RT-ResearchFlow 1.18 候选

在统一产品的策略评估页加入样本外与滚动验证：预先固定信号来源、资金假设、候选持有期和质量门槛，仅用训练窗口选参数，再执行不重叠测试窗口。显示逐步进度，支持步骤间暂停与本地恢复，历史报告保持不变。

样本外亏损不隐藏，缺少数据不记零收益。独立窗口预算重置，窗口统计不冒充连续实盘净值、收益保证或线上交易验收。研究事实仍有价格口径、历史信号当时可得性与逐报告快照限制。
