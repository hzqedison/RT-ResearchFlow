# RT-ResearchFlow 1.20

本轮修正交易恢复后的重新授权入口。安装包只在三端原生构建、Windows 安装生命周期和原字节发布检查通过后交付；公开状态及下载以 GitHub Releases 为准。

## 本轮变化

- 修复恢复后无法重新授权的死锁：全部未决意图核对完后，即使订单准备仍被禁止，也可以申请新的本人会话授权。
- 授权与下单分开。恢复、人审和勾选风险确认不会自动启用交易或重发旧订单；每笔仍须本人确认。
- 原交易页面提示重新授权下一步。待核对、退出未证明、状态读取失败及回报未知仍保持保护。
- 修正首页旧版本介绍和开发分支，保留明确的正式包与开发候选区别，不提前提供不存在的下载。

## 验收范围

本地八个交易相关单元文件 373 项通过、1 项平台限制跳过；主进程与界面类型检查通过。实际 Windows 应用打开交易页、权限保持关闭、去敏诊断和正常退出检查通过。服务检查使用真实 SQLite、受监督合成旧来源、原生确认取消、合成账户观察、旧意图不可变和退出重启，以及界面状态门禁。

这些证据不证明完整实际恢复交互、真实账户、同花顺布局、Tushare 在线权限、实盘成交或无人值守交易可用。Windows 不执行 Mac 专属交易桥接。三端正式产物证据分别记录于发布附件；生产安装及个人数据未被覆盖。
