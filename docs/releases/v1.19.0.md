# RT-ResearchFlow 1.19

统一的本地投研、策略与量化工作台，Windows 与 Mac 使用同一产品功能。

## 本轮改进

- 筹码结构和机构证据同步接入统一退出管理：停止新任务，取消进行中的请求，等待已登记任务收敛。
- 日线、筹码表现、筹码分布和机构请求在返回后、落库与阶段切换前检查取消状态，保留已成功保存的事实。
- 取消状态与真实数据源失败分开：不把退出记为接口故障，不误发正常同步完成事件，不向已经销毁的窗口发送进度。
- 保留原有的机构证据口径：公开龙虎榜席位不代表全部机构交易，也不作为筹码身份比例。

## 发布条件与范围

公开安装包必须在同一源提交上完成三端原生构建、实际程序检查和 Windows 安装生命周期验收。新增四类筹码结构退出场景必须逐端通过，验收附件中的 `localChipStructureWorkShutdownVerified` 必须为 true；缺失记录不能发布。发布复用已测安装包，不重新编译，也不覆盖旧版本。

随包验收 JSON 与 SHA256 清单用于核对版本、提交和安装包字节；它们不是收益、全部后台任务或所有历史升级路径的保证。

未使用用户真实 Tushare Key，未接受线上行情验收，未连接券商或提交订单。Tushare 绑定入口保留，但权限需用户本机验证。数据扩展仍按需安装到应用专用数据目录，不替换共享系统 Python。
