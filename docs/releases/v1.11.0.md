# RT-ResearchFlow 1.11

## 本次更新

- 数据源页面顶部新增明确的 Tushare Key 绑定入口，免费数据源不会隐藏它。支持绑定新 Key、复查已绑定 Key，并展示实际验证时间与检查接口。
- 区分“已加密绑定”“未验证”“交易日历验证通过”“权限受限”和“验证未完成”。绑定不会自动开启全市场拉取，失败不会覆盖旧 Key。
- 免费涨停池直接使用东方财富公开接口，无需 Token 或 Python。保存时保留源站日期和核对证据，不混入原有专业数据表。
- 免费规则选股提供早封首板、二板观察和连板观察，显示阈值、排序与匹配依据，可打开个股走势。
- 根据完整本地交易日历建议最近已收盘交易日，不再默认选择周末或尚未收盘日期；手动日期不会被覆盖。
- 当前公开题材支持按股票查询本地成分与来源时间；不冒充历史题材成分。

## 使用入口

Tushare：配置中心 → 数据源 → 顶部“Key 绑定与验证”。此处填写 Tushare 金融数据 Token，不是 DeepSeek 等大模型 Key；绑定后需要使用专业数据时再勾选下方 Tushare 并保存。

免费涨停池：配置中心 → 数据源 → 东方财富涨停池，检测后核对并保存，再到短线页面的免费观察和规则选股查看。

## 能力边界

本次 Key 验证只测试交易日历的实际返回。竞价、分钟线、筹码等付费接口仍需各自权限，并未因绑定成功而自动验证全部权限。免费涨停池不是完整的全市场涨跌停及炸板数据；规则筛选不预测收益，也不自动提交订单。

Windows 安装包覆盖原有安装目录，产品专用环境保存在该目录的 data 中，默认优先非系统盘。Mac 与 Windows 属于同一产品。Mac 提供 Apple Silicon 与 Intel 的独立 DMG；当前未承诺 Apple 公证。
