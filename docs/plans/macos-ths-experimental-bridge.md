# Mac 本机同花顺交易实验桥接

## 2026-10-07 的新证据

找到专门面向 Mac 同花顺的开源实现：
- https://github.com/zetatez/evolving ，MIT，锁定参考提交 c6119456fb035d3f3348da675bb1b6a68ee79391（2026-08-21）。
- https://github.com/learnerzhang/trade ，Apache-2.0，2020 年旧实现，仅作为历史路线线索，未复制其代码。
- https://github.com/shidenggui/easytrader/issues/460#issuecomment-2745924856 ：维护者说明其 Mac 支持限于雪球组合，不能当成 Mac 同花顺连接器。

参考实现提供 AppleScript 买卖、查询、模拟操作，但大量使用固定控件位置、盲目确认与全撤，且脚本的 shell 包装不能直接作为 osascript 的 -e 内容执行。新适配不直接执行下载代码，不安装 Go、Python、Homebrew 或 cliclick，不复制登录/转账能力。

## 本版可运行的实验功能

从“量化开通 > 交易实验”进入，先由本人手动登录同花顺、打开交易页。
实际通过 Mac 本机 /usr/bin/osascript 访问同花顺，而不是虚构远程接口或本地假钱包。

1. 检查辅助功能/自动化权限、交易页和三个订单输入控件。
2. 填写买入/卖出代码、限价、数量，回读核对；实盘预览还需识别中信证券标记，不点击提交。
3. 仅同花顺模拟模式支持提交；确认模式可识别、参数回读一致、委托表头可识别后，才触碰模拟提交按钮。
4. 唯一新增委托编号只表示受理，不等于成交；异常、超时或确认弹窗不明时锁住重复提交。
5. 查询按钮在同花顺本机打开委托/成交页面，不读取账户表格或资金。
6. 模拟单笔撤单仅识别精确编号和单笔撤单按钮；不使用全撤或坐标双击。此版尚未自动核对撤单回报，触碰撤单后结果保持不明，须本人核对。
7. 导出去敏状态：平台、架构、动作、模式、结果码、保护状态。无账号、密码、Key、余额、持仓、委托编号、订单参数、路径或原始日志。

只适配普通 A 股主板限价表单。科创板、创业板、ETF、转债、自动登录、资金转账和无人值守实盘均不包含在本版范围内。

## 仍待她本机验证

开源仓库宣称支持不能证明当前同花顺版本或中信账户可用。
模式按钮必须提供可靠选中状态；控件不同则停止，不盲目猜测。第一轮反馈只需去敏状态，定位模式、控件、表头、确认或回报哪一步未兼容。
Mac CI 能检查脚本语法、输入约束、去敏边界和安装版入口；没有她的同花顺账户，不能证明模拟委托实际受理或实盘可执行。

这只是走向“Mac 本机 + 同花顺自动交易”的实验接入阶段，不视为完整目标完成。
下一阶段需要按本机反馈调整控件映射，增加成交/撤单回报核对与幂等执行，再在明确权限和风险边界后讨论实盘自动执行。

## 数据源不能因此全部删除

桌面交易桥接不提供完整历史行情、财报、资讯、题材、筹码或模型服务。保留现有数据源和 AI Key 配置。只有拿到可用且允许使用的数据后，才能按字段、历史范围、频率与质量逐项替换。
