# 中信证券与同花顺 Mac 自动交易：公开资料补充

资料核实日期：2026-10-07。

本文补充概念规划，不是开通成功证明或已实现功能说明。只记录公开资料，不记录个人账户、资金、密码或截图。最终目标仍是在 Mac 上使用自动交易；接入方式尚未确定。

## 结论先行

中信有量化交易产品，但普通同花顺 Mac 的交易界面不能证明拥有程序下单权限。需要分清三件事：终端能手动交易、账户获准程序化交易、外部程序获准调用交易接口。它们不能互相替代。

## 已有官方依据

| 事项 | 已确认的信息 | 不能据此推断的内容 |
| --- | --- | --- |
| 中信的量化产品 | 官网公示 CATS 和迅投 QMT；普通 Mac 交易软件另列 | 个人账户一定可开通、具备外部下单接口、存在 Mac 量化版本 |
| 程序化交易流程 | 首次交易前向券商报告，获得券商确认；协议允许电子或纸质签署 | 某个 App 菜单可直接办完、签了协议就已获得 API 权限 |

| 非 Windows 支持 | 迅投 Linux 版文档明确仅支持取数，不支持交易 | Linux 包或 ARM 包可以直接在 Mac 上完成交易 |
| 同花顺数据接口 | iFinD 官方支持 Mac 使用 HTTP 取数；普通终端与数据接口不能混为一谈 | 免费 Mac 客户端附赠完整接口、数据接口就是交易接口 |

本次没有查到可证明普通同花顺 Mac 具备受支持的外部自动下单接口的官方资料。这是证据不足，不是断言任何 Mac 方案都不可能。

## 开通与接入清单

以下是我们的准备顺序，不是中信已承诺的固定办理流程。

1. 通过中信官方客服或实际开户营业部，提出“个人账户、自编程序、自动交易”的业务需求。已有证券账户不等于必须重新开户，先核实原账户能否办理。
2. 要求券商确认可提供的具体产品和权限：完整 QMT、MiniQMT 外部函数下单、CATS 或其他正式接口；同时取得操作系统、模拟环境、申请材料和费用说明。
3. 按券商要求办理适当性审核、相关协议和交易前报告。报告涉及账户、资金、策略与申报频率、软件信息、联系方式；数值必须按实际方案填写，不现在编造。
4. 取得券商确认及接口说明后，再确定实施路线，先只读接入、模拟验证、故障演练。系统上线还需符合券商的测试与风控要求，不能把一次接口连接成功当作实盘验收。

流程依据为上述 2026-07-06 中信开户文本中的程序化交易协议。不得将协议里的券商向交易所报送期限解读为“开通一定五天内获批”。

## 办理渠道与非交易日

中信官方服务电话为 95548。官网列出的证券业务咨询时间为每个交易日 9:00-22:00；热线委托的全天服务不等于量化权限审核全天办理。因此今天可以完成资料准备，不能保证今天有人审批或开通。

依据：[中信客服中心业务介绍](https://www.cs.ecitic.com/newsite/ywzx/callcenter/ywjs/201710/t20171027_69587.html)。

向客服说明的需求要点：已有个人中信账户，使用普通同花顺 Mac，准备基于开源投研软件自行开发自动交易；希望确认现账户的程序化交易办理方式、外部下单权限、Mac 支持、模拟环境、门槛费用和自编软件审核要求。只通过官方渠道提交身份材料，不把密码、验证码发给开发助手。

## 仍不能确定的账户条件

- 该账户是否受理个人程序化交易，具体由哪个营业部办理。
- 资金门槛、风险等级、交易经验、账户类型、软件或数据费用。
- 是否提供 MiniQMT 外部下单权限，以及可使用的实际接口版本。
- 是否允许自编软件、如何报告开发主体及软件版本、需要何种测试材料。
- 是否有原生 Mac 或适用于 Mac 的正式远程交易接口。
- 模拟环境、行情授权、交易品种、请求限制及多终端登录规则。

未找到足以确认上述条件适用于该个人账户的官方公开材料，不采用广告文章中的“10 万、50 万、100 万”等数字，也不因第三方网站自称可开通就推荐转账、开户或购买服务。

## 对产品规划的影响

| 候选路线 | 当前状态 | 实施前提 |
| --- | --- | --- |
| Mac 原生应用通过同花顺的正式交易接口 | 唯一正式接口候选，未验证可用 | 同花顺确认 Mac 接口，中信确认对应账户权限及规则 |
| Mac 操作界面加 Windows 执行端 | 用户已明确排除 | 不实施，不再作为默认备选 |
| Mac 上自动操作普通同花顺界面 | 不作为默认实盘方案 | 另行评估支持政策、界面稳定性、回报核对与故障风险；不绕过报告要求 |

用户已明确只接受 Mac 本机，必须通过同花顺交易。绕开同花顺直接走其他客户端或券商接口的方案亦已排除；此前的备选描述不再生效。

现有 Windows 工作区只用于开发和构建，仍优先使用 D 或 K 盘；不增加 Windows 交易执行端，不默认购买设备。

规划中的安全边界：自动交易与现有只读投研服务隔离；交易启用需用户明确授权；报价过期、账户状态不明、订单回报未核对或断线时停止新申报；保留人工停止入口。这里只确定设计方向，不预设交易策略或风险额度。

## 数据源不能直接删除

iFinD 的 Mac HTTP 取数是可研究的替代来源，但需要单独确认授权、字段、历史范围和更新频率。其所谓免费接口账号是购买 iFinD 终端后附带少量接口权限，不等于普通免费同花顺客户端自带完整数据接口。[官方说明](https://quantapi.10jqka.com.cn/gwstatic/static/ds_web/quantapi-web/help-center/faq.html)

我们的方案是保留统一数据层，取得合法可用的数据后，只替换确实覆盖的来源；没有覆盖的公告、历史或其他研究输入保留原通道。交易授权、数据授权和大模型服务密钥分别管理。

与概念规划配套使用。得到正式接口资料和账户办理答复后，再展开可验收的实现计划。

## 本轮开通引导与反馈边界

用户已同意先提供量化交易开通引导；使用方只能反馈本地运行结果，不能向开发方提供敏感账户材料或远程操作权限。

引导进度仅保存三个布尔标记：已申请、已收到官方回复、理解数据权限。诊断文件只输出固定路线、Mac 环境分类、这些标记、接口尚未实现与账户尚未核验的状态，以及固定阻断码。采用白名单构造，不把原始日志脱敏后冒险导出。

本轮没有交易连接器，也没有提交订单的方法。引导全部完成或修改本地存储都不能解锁下单。未来的连接器需要在她的 Mac 上独立核验，再进行模拟与回报核对；只反馈脱敏结果不能代替账户权限本身的本地验证。

同花顺官方确有智能交易和 PythonTrader 文档，但不能当作普通 Mac 版的接口证明。PythonTrader 安装说明涉及 Windows 可执行文件，相关资料较旧；智能交易平台里的条件单也不自动等于普通 Mac 客户端具备相同能力。[智能交易说明](https://quant.10jqka.com.cn/view/help/22)、[PythonTrader 准备工作](https://xdres.10jqka.com.cn/help/python/site/g_prep/)
